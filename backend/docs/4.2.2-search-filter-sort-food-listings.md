# Prompt: Implement SRS 4.2.2 - Search, Filter, and Sort Food Listings

Implement backend-first search, filter, and sort for Donor food listings in the AFF backend. Follow the existing modular monolith flow: route -> controller -> service -> repository -> Mongoose model -> DTO response.
Ensure that the sorting and filtering feature will use a medium level algorithm, do not use or implement the advanced or hard to explain in code algorithm 
For the searching mechanism, as said, the search will focus on backend, using explainable algorithm do not use advnaced algorithm either. 
The CreatedDate and Revenue will be use from donation.js in models

## Flow

1. Donor calls `GET /api/donor/food-listings` with optional query params.
2. Controller reads the authenticated `donorProfileId` and passes query params to the donor listing service.
3. Service validates and normalizes search, category, created date range, sort field, sort direction, page, and limit.
4. Repository builds one MongoDB query object and one sort object, then executes `find()` and `countDocuments()` with `Promise.all`.
5. Controller returns paginated entries and metadata for the frontend dashboard.

## Mechanism

Use the existing `Donation` model fields:

- `name` for listing-name search.
- `foodCategory` for category search/filter.
- `createdAt` for date range filtering and sorting.
- `revenue` for revenue sorting.

Add accepted query params such as:

- `search`: case-insensitive pattern search on listing name.
- `foodCategory`: exact category filter.
- `createdFrom` and `createdTo`: date range filter.
- `sortBy`: only `createdAt` or `revenue`.
- `sortOrder`: only `asc` or `desc`.
- `page` and `limit`: pagination.

## Algorithm

Build the MongoDB filter step by step:

```js
query.donorProfileId = donorProfileId;
if (search) query.name = new RegExp(escapedSearch, "i");
if (foodCategory) query.foodCategory = foodCategory;
if (createdFrom || createdTo) query.createdAt = { $gte, $lte };
```

Build the sort object from a whitelist:

```js
sort = { [sortBy]: sortOrder === "asc" ? 1 : -1 };
```

Then run:

```js
const [entries, total] = await Promise.all([
  Donation.find(query).sort(sort).skip(skip).limit(limit),
  Donation.countDocuments(query),
]);
```

This is medium-level because it combines search, exact filters, range filters, sorting, and pagination while staying explainable and aligned with the existing repository layer.
